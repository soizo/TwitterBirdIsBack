# Localization evidence

## Scope

All 45 display-language options restore the Twitter brand. English (including British English), Simplified Chinese, Traditional Chinese, Japanese, Korean, Vietnamese and Polish additionally restore verified historical Twitter terminology. Other languages intentionally retain current action wording. Coverage includes UI labels, detail headings, hover hints, native `title` and accessible labels, the translation-entry icon, and tab titles. User-authored text, display names and search queries must not be translated or rewritten.

Language resolution, interface branding, title grammar and translation-entry icon matching have 45-locale regression fixtures. Detailed terminology uses eight locale options (the seven requested language groups, with British English separate). Popup localization remains independent and unchanged. Verified terminology catalogues do not cover arbitrary future UI copy.

Public bundle URLs for every locale are recorded in `locale-sources.json`. Captured input labels live in `../test/fixtures/x-locales.json`. Canonical aliases confirmed in the first-party bundle map include `en-gb → en-GB`, `msa → ms`, `no → nb`, `zh-cn → zh`, and `zh-tw → zh-Hant`.

## Priority implementation and limits

- Website language comes from the HTML language tag; popup language comes from the browser. The shared registry normalizes tags to existing display options. Unsupported website wording is left alone; generic trailing site branding still works.
- English and British English retain the established casing and notification rules. Other detailed locales use full-string mappings in `extension/classic-locales.js`, generated by `scripts/generate-classic-locales.py`. Conflicting targets and the unrelated sports abbreviation `POST` (`bf81d3e2`) are excluded. Posting actions, heading nouns, counted labels and title templates are separate.
- The generator matches modern and historical English meanings to discover changed identifiers, then reads the corresponding first-party translations. It parses literals and a restricted concatenation/plural grammar, never executes downloaded JS, and caches by immutable resource filename. Unrecognized syntax fails generation.
- Localized notification allowlists derive from the 50 checked English notices. Two old errors require explicit identifier pairs because the historical English said “Try Retweet.” The newer highlight/boost success notices (`a50c911e`, `ie08d3a4`) retain their modern meaning and grammar, substituting only the verified historical noun. Duplicate localized strings collapse; conflicting mappings are skipped rather than guessed.
- Spanish, Russian and Ukrainian now use brand-only restoration as requested; their earlier historical evidence is retained below for reference. Vietnamese uses `vi.58b1d9da.js` for actions, headings, notices, composer prompts, counters and title grammar.
- Localized text changes edit only the changed span of existing text nodes. SVGs, links, listeners and protected user text survive, including split notifications. Unknown messages and unimplemented interpolated-name templates remain unchanged. Title captures are inserted once without interpreting replacement metacharacters.

`test/priority-classic.test.cjs` and its independently recorded fixture exercise the eight detailed locale options, native hints, counted states, split text, dynamic updates, title captures and protected content. These are browser tests against local page fixtures, not a claim of exhaustive live-account verification in every language.

## Previous Discover more workaround (0.1.6; superseded by 0.1.7)

The user supplied the live Simplified Chinese subtitle “源自于整个 X”. The original short-hint path was English-only. The module now has a separate language-independent brand restoration path: a direct subtitle sibling of the official Discover more heading (`d172116a`), inside a timeline cell and main content. The 45 heading values come from the existing first-party snapshots in `locale-sources.json`; an independently recorded heading fixture is in `test/fixtures/discover-headings.json`. Only the standalone ASCII brand token is replaced, preserving localized surrounding text, inline elements and protected content. Interactive descendants and subtitles longer than 160 characters are excluded.

Tests exercise the reported Chinese subtitle and a split English subtitle under each of the 45 official headings. These mixed-language fixtures intentionally verify structural language independence, not the authenticity of other languages’ subtitle wording. No new localized subtitle translations are guessed.

## Context-aware brand matching (0.1.7)

Interface branding no longer needs an exact sentence, a Discover more heading, or a specific timeline-cell structure. It recognizes uppercase X outside larger Latin words, numbers, handles, hashtags and URLs, allowing adjacent CJK/Korean text and apostrophe suffixes. Eligible surfaces are main content, navigation, sidebars and dialogs. Posts/articles, recognized profile fields, account links, message text, cards, trends, notifications and editable fields are excluded; bare-X close buttons are preserved. Fine terminology restoration runs first, then branding, so a brand edit cannot prevent a verified terminology match.

Text edits target each brand character in its original text node, preserving split spans, sibling text positions and listeners even with several occurrences. Attribute updates and newly inserted/changed content reuse the same policy. This is deterministic local context matching, with no model calls or external translation service. Interface redesigns or unidentified user-content containers can still require updated exclusions; these heuristics are not a claim of perfect semantic understanding.

All 45 official `a4d3eb67` title templates are recorded in `extension/locales.js`, with independent fixtures in `test/fixtures/brand-titles.json`. Brand-only title changes apply to the literal template before inserting the captured name and post. The Vietnamese historical source is https://abs.twimg.com/responsive-web/client-web/i18n/vi.58b1d9da.js. Local browser fixtures cover the language tiers, dynamic text/hints, multi-occurrence split text, protected content, brand boundaries and title captures; this is not live-account verification in every language.
