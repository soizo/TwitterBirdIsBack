# 开发与维护指南

本文面向开发者和维护者，记录实现边界、源码位置、测试要求与打包流程。安装和使用说明见 [项目首页](../README.md)。

Twitter Bird Is Back 是原生 Manifest V3 扩展，无运行时依赖。以下文件路径和命令均相对于仓库根目录。

## 经典界面

- 界面控件和状态标签中的 `Post / Posted / Posts` → `Tweet / Tweeted / Tweets`，`Repost / Reposted / Reposts` → `Retweet / Retweeted / Retweets`，保留常见大小写形式，并处理动态加载和重绘。
- 悬停提示（`HoverLabel`／`role="tooltip"`）、原生 `title` 和无障碍标签同步恢复操作用语，包括 `Undo repost`；任意提示正文不做逐词替换。
- 英文系统通知（toast／alert）统一恢复已核对的 50 条官方文案：发送、转发、书签、置顶、回复、草稿／定时发布删除及失败提示等。包括 `Your post was sent.` → `Your tweet was sent.`、`reposting` → `retweeting`；支持初始、动态、拆分文本及提示属性。未知通知、用户姓名和正文不纳入新增通知规则。
- 详情页及其子页面的主标题同样恢复 Tweet／Tweets／Retweets，支持单页导航和重绘；资料页标题不纳入替换，避免改写用户显示名。
- 不做整页文字替换；跳过推文正文、已识别的用户名／用户资料区域和输入内容。未识别的界面区域可能仍显示新用语。
- 侧栏与编辑框发帖按钮、Follow 按钮：背景 `#1DA1F2`，悬停 `#168BD2`。文字和图标在浅色、深色模式下统一使用白色；不依赖网站或系统主题。
- 不改变点击逻辑和禁用状态，不覆盖 Following／Unfollow 的样式。
- 翻译入口图标识别 X 的全部 45 个显示语言选项对应的官方按钮文案，只替换按钮前紧邻的 Grok SVG；保留原尺寸、颜色及行为，支持延迟出现，其他 Grok 图标不变（另有可选的 Grok 入口隐藏开关）。
- 网页用语与标题优先支持 9 个官方语言选项：英语、英式英语、简体中文、繁体中文、日语、韩语、西班牙语、俄语和乌克兰语。跟随网页显示语言，不跟随浏览器语言强行改写网页；其他语言的用语保持原样。
- 非英文使用官方新旧资源核对后的完整文案映射，区分发帖动词与详情页名词，处理撤销、计数状态、提示和系统通知。仅修改必要的文本节点，保留 SVG、链接、事件处理及用户内容；未知文案或有歧义的映射不猜译。
- `extension/locales.js` 负责语言解析，`extension/classic-locales.js` 保存可再生成的文案目录。覆盖状态、限制及官方来源见 [多语言核对记录](localization.md)。
- 图标逻辑在 `extension/content.js`；用语和按钮样式在 `extension/classic-ui.js`、`extension/classic-ui.css`。

## 弹窗开关

点击浏览器工具栏的扩展图标，可控制总开关和九个分项。蓝鸟与网站图标、旧版操作用语、经典蓝色按钮、翻译地球图标、标签页标题、真实链接默认开启；以下三项默认关闭：

- **隐藏所有 Grok 入口**：隐藏已识别的 Grok 导航、动作按钮、资料摘要、图片生成、推文内推荐问题和 Grok 浮动区。保留普通翻译、用户正文／资料里的链接，以及 `@Grok` 用户的资料页和关注按钮。不拦截网络或禁止直接访问 Grok。
- **隐藏右下角 Grok 和 Chat**：一起隐藏 Grok／Chat 浮动区（兼容旧版 Messages 浮动区），不隐藏普通聊天导航。与上一项独立，可同时开启。

- **隐藏 Edit image 按钮**：独立隐藏 `href` 以 `/i/grok-redirect?` 开头且含 `%26action%3Dimg_edit` 的链接，兼容动态插入，不影响其他 Grok 入口。

这些规则使用已核对的标识、图标及官方按钮文案；网站新增或改变入口结构时可能需要适配。

- 勾选即自动保存；设置保存在当前浏览器的 `storage.local`，不跨设备同步。
- **手动刷新 Twitter 页面后生效**，不自动刷新，也不改动当前页面上的编辑内容。新打开的页面直接读取最新设置。
- 关闭总开关只暂停修改，保留分项选择；重新开启后沿用原组合。
- 弹窗使用白底黑字、少量 Twitter 蓝和原生复选框。支持英语／英式英语、简体中文、繁体中文、日语、韩语、西班牙语、俄语和乌克兰语；按浏览器语言选择，其他语言回退英文。地区标签归一到 X 已有选项，例如 `zh-HK` 使用繁体中文、`es-MX` 使用西班牙语，不新增语言版本。网页经典用语的适配状态与弹窗翻译分开记录。
- 读取或保存失败会明确提示；读取失败时页面不应用修改，保存失败时勾选恢复为此前的状态。
- 设置逻辑在 `extension/settings.js`；弹窗在 `extension/popup.html`、`popup.css`、`popup.js`，文案在 `extension/popup-locales.js`。只新增 `storage` 权限。

## 真实链接（Actual link）

- 默认开启，由 `extension/actual-links.js` 独立处理，不依赖其他分项；总开关关闭或设置读取失败时不修改链接。
- 只处理 HTTP(S) `t.co` 链接：优先读取非空 `title`，否则读取完整 `textContent`（包含隐藏的协议前缀），使用 `URL` 校验并更新 `href`。例如示例中的短链恢复为 `https://github.com/soizo/FreeNumi`，普通点击和浏览器复制链接使用直链。
- 不修改链接文案、子元素、样式、`target`、`rel` 或事件处理器；跳过可编辑内容。观察新增节点、`href`／`title` 和文字变化，支持重绘；地址变得不完整时恢复该节点原来的短链，网站主动设置的新非短链不覆盖。
- 没有协议、带省略号、空白／控制字符、反斜杠、账号密码、无效 URL 或非 HTTP(S) 的目标保持原样。不请求短链、不猜测被省略的地址、不新增权限。
- 页面提供的地址不等于经过独立验证的短链目标；直链会绕过 `t.co` 跳转及其可能显示的安全提示。不需要此行为时可关闭分项并刷新页面。
- `test/popup.test.cjs` 在实际加载扩展的 Chromium 中验证默认值、开关持久化／刷新生效、直接打开目标、动态重绘及不应改写的反例；尚未验证真实 Twitter 页面点击事件或 Firefox 实机行为。

## 登录／注册页品牌区

- 复用蓝鸟开关，识别已采样的 `480×490` 注册页品牌 SVG 和精确路径；支持两套页面结构、亮／暗主题。把包含描边和渐变的整组图形替换为单个经典蓝鸟，更新 `viewBox` 与无障碍名称，不触碰登录表单、第三方提供商图标或用户内容。
- 宽屏蓝鸟最大宽度为 360px；沿用已观察到的 850／851px 布局边界，窄屏缩至 80px，并取消仅包含图标的容器的大块最小高度。保留网站自身的显隐断点、背景色和表单布局。
- 支持动态插入，以及已识别 SVG 的路径、子节点或 `viewBox` 重绘。其他未采样的品牌图形不猜测替换。
- `test/signup.test.cjs` 只保存必要的 SVG 路径和布局夹具，覆盖两套结构、两种主题、1440／800／414px 宽度、表单值／事件保留、动态重绘及开关独立性；不提交完整网页快照或会话数据。离线快照检查不等同于真实账号的注册流程验证。

## 标签页标题

规则在 `extension/title.js`。首批语言使用各自已核对的旧版标题结构，不做全文词语替换；下列为英文示例。

- `(8) Home / X` → `(8) Home / Twitter`，保留未读数量。
- 注册页固定标题 `X. It’s what’s happening / X` → `Twitter. It’s what’s happening / Twitter`，也修复旧版本只改过末尾站名的标题，兼容直引号；不替换用户名称中相似的词句。
- `Post / X` → `Tweet / Twitter`；固定页面名也覆盖 Posted／Posts／Repost／Reposted／Reposts。
- `Alice on X: "I use X" / X` → `Alice on Twitter: "I use X" / Twitter`，不改引号内正文。
- 用户名、搜索词和引号内正文保持原样，包括 `$&`、`{text}` 等特殊文本。若标题分隔符有歧义，保留主体，只恢复末尾站名；未适配语言也保留既有通用站名恢复。
- 支持初次加载、未读数更新、单页导航和标题节点重建。

## 扩展图标

用户提供的原始素材保存在 `assets/`。透明版等比缩放为工具栏、扩展管理页和弹窗图标；白底版保留作展示素材，不随扩展打包。网页启动屏、站内品牌标志和网站图标仍使用经典蓝鸟。

扩展自身的可见文案统一使用 Twitter。实际域名、匹配条件及官方来源记录不作虚假改名。

## 本地开发

```sh
npm ci
npx playwright install chromium
npm test && npm run build
```

每轮修改都先通过测试，再构建 `dist/`，供浏览器加载预览。DOM 测试使用本机安装的 Google Chrome；启动屏和弹窗测试使用 Playwright Chromium，在隔离配置中真实加载扩展。启动屏测试阻塞页面加载检查启动阶段；弹窗测试使用真实扩展存储检查分项开关、刷新生效与持久化。

重新生成资源（仅开发时运行，不执行下载的官方脚本）：

```sh
python3 scripts/generate-classic-locales.py --output extension/classic-locales.js
node scripts/build-icons.cjs
```

网页多语言测试使用独立记录的预期文案和本地页面夹具；并不代表已逐语言验证真实账号的所有界面变体。

修改用语时按界面位置逐项检查：按钮正文、详情标题、菜单／撤销状态、真实 hover 提示、原生 `title`、无障碍标签和 tab title；覆盖动态出现与重绘，并保留正文、用户名、搜索词的反例测试。不要只检查按钮正文就视为完成。

## 加载与更新

- **Chrome**：打开 `chrome://extensions`，开启开发者模式，点击「加载已解压的扩展程序」，选择本项目的 `dist/`。
- **Firefox**：打开 `about:debugging#/runtime/this-firefox`，点击「临时载入附加组件」，选择 `dist/manifest.json`。临时加载在浏览器重启后失效。
- **每次构建后**：在对应扩展管理页点击扩展的「重新加载」，再刷新 x.com。不是自动热更新。

## 长期安装与发布包

运行 `npm run package`，更新固定安装目录 `dist/` 并在 `releases/` 生成两个以当前 manifest 版本命名的 ZIP，以及 `SHA256SUMS`。ZIP 根目录就是 `manifest.json`；只包含扩展运行文件，没有源码仓库、测试、研究缓存或原始展示素材。打包使用 Python 3 标准库。

- **Chrome / Chromium**：继续加载当前项目的 `dist/`，不要移动该目录。重启浏览器仍保留安装；升级时重新构建并在扩展管理页点击重新加载。Chrome ZIP 用于备份或分发，不能把它当作已签名安装器直接安装。其他电脑可解压到自己的长期固定目录，再加载已解压扩展。
- **Firefox 桌面版 140+**：`*-firefox-unsigned.zip` 是提交 Mozilla Add-ons 审核的待签名包，不能在正式版 Firefox 中直接永久安装。公共版本获批后从 Mozilla Add-ons 产品页安装和更新。
- Android 最低版本声明为 142，以满足数据声明字段的兼容性要求；这不代表已完成 Android 实机测试。
- Firefox 包包含固定 ID `twitter-bird-is-back@soizo`，后续升级必须保留它并递增版本号。
- Firefox 包声明不收集数据：扩展仅在本地处理页面，设置只保存在 `storage.local`，不向外发送用户数据。该声明不代表 Twitter 网站本身不联网。
- 升级前保留旧版 ZIP 和校验文件；正式签名后的 `.xpi` 也应另行保存。不要删除现有扩展后重装来升级，以免丢失设置。
